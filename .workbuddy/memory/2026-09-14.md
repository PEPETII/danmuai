## DanmuAI 知识库修复（生命周期 / 错误协议 / 前端假成功 / 视觉检索）

### 改了什么

- `app/knowledge/runtime_service.py`
  - 新增终止态 `_closed`（`is_closed` 属性）；`mount()` 在 `_closing or _closed` 时直接返回 False，绝不重建第二套 DB。
  - 新增 `_discard_partial_state()`：同步关闭 orchestrator+db 但**不**置终止态，供 mount 失败自清理使用（替换原先误用的 `close(wait=True)`）。
  - `close()` 走 `_finish_close_after_imports()` → `_discard_partial_state()` → 最后置 `_closed=True`。
  - 新增模块常量 `SCENE_CONTEXT_REUSE_MAX_AGE_SEC = 180.0`；`get_last_scene_context(..., max_age_sec=)` 可收紧默认 TTL（900s）。
  - `build_visual_prompt_injection` 记录场景上下文时：同语义重复注入**保留原 updated_at**，避免复用窗口被无限往后推。
- `app/main_lifecycle_mixin.py`
  - `_ensure_knowledge_runtime` 增加 `_closed` 判定（已终止不得复活）。
  - `start()` 的 `_ensure_knowledge_runtime()` 返回值参与判定，失败只记 `reason=knowledge_disabled` 警告，弹幕主链路继续。
  - `stop()` **不再**关闭知识库运行时（运行时属于整个应用生命周期）；仅 `quit()` / `release_startup_failure()` 以 `close(wait=True)` 关闭。
- `app/main_request_context_mixin.py`
  - `_build_knowledge_scene_context`：本轮无语义时复用同代际内 180s 以内的上一轮真实语义，不伪造 `round=/screenshot=` 占位查询。
- `app/web_api/knowledge.py`：`preview_retrieval` 空查询提前返回 `missing_query`。
- `web/static/modules/*`（transport / app-knowledge-*）：`apiFetch` 非 2xx 带 `error.status`/`error.code`；新增 `assertKnowledgePayload` / `knowledgeErrorMessage` / `humanizeKnowledgeApiError`；所有写操作只在拿到有效 `package_id` / `job_id` / `ok` 之后才清输入、关弹窗、刷列表、起轮询。
- `web/static/locales/{zh,en}/dynamic.json`：新增 `appKnowledgePage.apiErrors` 与若干失败文案键（zh/en 键完全对齐）。
