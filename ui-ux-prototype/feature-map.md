# 功能分类与入口映射

## 分层定义

| 层级 | 判断标准 | 默认呈现方式 |
| --- | --- | --- |
| 核心 | 完成“识别画面 → AI 生成 → 弹幕上屏”闭环，或高频个性化 | 首屏或一级常用入口 |
| 增强 | 不阻塞核心闭环，但能明显扩展输入、表达或内容质量 | “增强体验”分组 |
| 高级 | 专业参数、复杂创作、直播集成、诊断、记录与维护 | 可展开高级入口 + 全部功能搜索 |

## 现有入口覆盖核对

### 侧栏 8 个主入口

- 温馨控制台 → #1–#5、#21–#22 的首屏摘要。
- 弹幕设置 → #3–#5、#9–#10、#17–#20。
- 弹幕样式 → #6、#8。
- 弹幕人格 → #7。
- 弹幕知识库 → #11。
- 公式化弹幕库 → #12。
- 虚拟主播 → #13–#15。
- 教程 / 日志 / 反馈 / 公告 / 群聊 / 直播 → #16、#21–#24。

### 弹幕设置 5 个真实分页

- AI 模型配置 → #3、#4、#17。
- 语音输入 → #9。
- AI 播报 → #10。
- 弹幕显示 → #5、#19。
- 画面识别范围 → #4、#18。

### 支持区 9 个真实分页

- 教程 → #23。
- 弹幕日志 → #21。
- 麦克风日志 → #21。
- 虚拟主播日志 → #21。
- 历史运行统计 → #22。
- 弹幕场次记录 → #22。
- 公告 → #23。
- 问题反馈与群聊 → #23。
- 直播输出 → #16。

### 非侧栏输出与全局能力

- Qt Overlay / 竖向弹幕浮动面板 / 横向弹幕：由 #1、#5、#6 管理入口，不改变真实输出面。
- `/live-overlay` 透明直播页：#16。
- 模型、更新、问题、知识导入等模态框：归入其对应的 #11、#17、#23、#24，不删除操作。
- 中文 / 英文、浅色 / 黑夜、官网与群聊、赞赏、版本更新：#20、#23、#24。

## 尚未由原型证明的事项

- “30 秒理解”必须通过真实首次用户计时测试证明。
- 原型没有连接 API，因此不能证明模型、截图、Overlay、TTS、知识库、Live2D 或更新链真实可用。
- 原型验证的是信息架构和可发现性，不是生产实现兼容性或视觉落地成本。
