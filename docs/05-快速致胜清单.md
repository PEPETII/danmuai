### 2. 提取 `@require_auth` 装饰器

**问题**：`app/web_api/` 下 68 处 `check_token(authorization)` 内联调用，跨 8 文件（routes.py 占 50 次）。每个写路由处理函数第一行都是 `check_token(authorization)`，无装饰器封装。

**改进**：创建 `app/web_api/auth.py`，实现 `@require_auth` 装饰器。

```python
# app/web_api/auth.py（新建）
from functools import wraps
from typing import Callable

from fastapi import HTTPException, Request, status


def require_auth(check_token: Callable) -> Callable:
    """FastAPI 路由鉴权装饰器。"""
    def decorator(func: Callable) -> Callable:
        @wraps(func)
        def wrapper(*args, request: Request, **kwargs):
            authorization = request.headers.get("Authorization")
            if not check_token(authorization):
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="Invalid or missing Bearer token",
                )
            return func(*args, request=request, **kwargs)
        return wrapper
    return decorator
```

**验证**：`tests/test_web_auth.py` + `tests/test_web_routes.py` 分批 `-q -x`。

### 3. 增加层级约束 docstring

**问题**：`app/application/__init__.py` 仅 5 行，docstring 声明「只读投影」但未明确禁止 `getattr(app, "_...")` 与 `app.__dict__`。

**改进**：扩展 docstring，增加明确的层级约束。

```python
# app/application/__init__.py
"""DanmuApp 边界收口层：只读投影、状态快照与 Web 配置写入。

不含 QTimer/QThreadPool，不触发主链路。

层级约束（强制）：
- 禁止 `from app.web_api import ...`（application 不得依赖 web_api 层）
- 禁止 `getattr(app, "_...")`（必须经 DanmuApp 公开 façade 访问）
- 禁止 `app.__dict__.get("_...")`（同上）
- 禁止 `from main import DanmuApp`（仅 `if TYPE_CHECKING:` 块内允许）
"""
```

### 4. 引入 `AppError` 基类

**问题**：全项目仅 2 个自定义异常类（`ConfigStoreCryptoUnavailableError(RuntimeError)` 与 `DanmuTtsError(Exception)`），分别继承不同基类，无共享父类，无法统一捕获。

**改进**：新建 `app/errors.py`，定义统一异常层次。

```python
# app/errors.py（新建）
from __future__ import annotations


class AppError(Exception):
    """所有项目自定义异常的基类。"""


class ValidationError(AppError):
    """输入校验失败。"""


class NotFoundError(AppError):
    """资源未找到。"""


class AuthError(AppError):
    """鉴权失败。"""


class ConfigError(AppError):
    """配置相关错误。"""


class TtsError(AppError):
    """TTS 请求或响应解析失败。"""
```

**迁移**（向后兼容）：

```python
# app/config_store.py:130（修改后）
from app.errors import ConfigError

class ConfigStoreCryptoUnavailableError(ConfigError):
    """Sensitive config cannot be stored without Fernet."""
```

```python
# app/tts_providers.py:62（修改后）
from app.errors import TtsError

DanmuTtsError = TtsError  # 向后兼容别名
```

**验证**：`tests/test_config_store.py` + `tests/test_danmu_tts.py` 分批 `-q -x`。

### 12. 增加 main_helpers.py doctest

**问题**：`app/main_helpers.py`（105 行）含多个纯函数（`reply_request_id`、`density_right_target`、`config_flag_enabled`、`queue_capacity`），但无 doctest 示例。

**改进**：为纯函数增加 doctest。

```python
# app/main_helpers.py（修改后示例）
def queue_capacity(items: list, max_items: int = 8) -> int:
    """计算队列剩余容量。

    >>> queue_capacity([1, 2, 3])
    5
    >>> queue_capacity([1, 2, 3, 4, 5, 6, 7, 8])
    0
    >>> queue_capacity([], max_items=4)
    4
    """
    return max(0, max_items - len(items))
```
