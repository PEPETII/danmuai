# DanmuAI v0.5.0

## 核心变化

- 从当前源码重新整理 Windows 发布候选，应用版本统一为 `0.5.0`。
- 保持 PyInstaller onedir → Velopack 的 Windows 构建链路；发布候选同时产出安装版与便携版。

## AI 模型

- 刷新模型目录与平台能力数据，继续通过模型档案选择全局活动模型。
- 保留模型平台、能力审计和启动模型状态的配置流程。

## 弹幕人格

- 内置弹幕人格升级为 14 个，新增 5 个角色人格，并将 `腹黑型`、`测试1`、`测试3` 兼容迁移为胡桃、阿库娅、银狼。
- 内置 Prompt 统一补齐角色身份、核心性格、观察偏好、反应逻辑、语言表现和行为边界；输出契约继续由统一人格契约注入。
- 补齐 14 个人格的 A/B 评测候选与 32 个场景样本。

## Web UI

- 删除温馨控制台的“快捷设置”区块及其 9 张入口卡片，功能配置仍从侧边栏和对应页面进入。
- 主入口和语言切换共用同一个设置模块实例，修复语言刷新无法读取主入口已加载的麦克风设备缓存的问题。
- 保持 HTML、locale、CSS 生成产物与源模板的一致性检查。

## 弹幕功能

- 保留统一活动模型供所有弹幕人格使用，并继续支持弹幕生成、显示和样式配置。
- 配置自动保存、增强功能侧栏和设置页面继续沿用当前 Web 控制台流程。

## TTS / 麦克风

- 保留麦克风输入、设备缓存、探针和 AI 播报配置页面；无凭据或设备不可用时使用可观察的错误路径。

## Live2D / 虚拟主播

- 保留虚拟主播、Live2D 模型导入与桌面渲染运行链路；外部用户模型不随发布包内置。
- 虚拟主播截图编码移到已有 scene worker，保持排队取消、在途请求与场景代际校验。

## 性能与稳定性

- 知识检索查询、缓存与计数写入增加容量、代际和过期门禁，并以有界批次处理持续写入。
- 配置导入与卡片渲染拆分准备、验证和绘制步骤，保留持久化与取消行为。
- CI 与本地构建继续使用明确的 Python 3.12 x64 release lock，拒绝锁外依赖漂移。

## 构建与发布

- Web utility CSS、HTML 和 locale 生成产物在构建前执行一致性检查。
- 发布候选使用 clean PyInstaller onedir 构建，再通过 Velopack 生成 Setup、full nupkg、可用时的 delta nupkg、Portable ZIP 和 update feed。
- MSI 不属于当前发布链路；R2 是主源，GitHub Releases 为镜像入口。

## 兼容性 / Breaking Changes

- 应用版本从 `0.4.3` 升级为 `0.5.0`；历史 release 文档保留原版本记录。
- 人格统一使用已启动的全局 AI 模型，不再提供单个人格独立模型选择。
- 发布包不包含 API Key、Supabase credential config、用户配置或本地数据库；用户数据仍由安装目录与 `%APPDATA%\DanmuAI\` 分离策略管理。
