# DanmuAI v0.4.3

发布日期：2026-09-04

## 更新内容

- 优化知识库导入、来源提取、内容校验、SQLite 仓储和运行时检索流程，并改进知识库页面的模块化展示与刷新体验。
- 为回复队列增加容量边界，补充运行诊断与失败路径处理，降低高频回复场景下的无界增长风险。
- 改进虚拟主播、Live2D overlay、麦克风路由、会话上下文和响应调度之间的协作。
- 完善 TTS provider 凭证隔离与相关设置界面。

## 修复

- 修复 MiMo TTS 配置保存相关问题。
- 修复 Windows 环境下 Uvicorn 事件循环处理问题，改善打包应用的本地 Web 控制台启动稳定性。

## 使用说明

- 安装版：运行 `PEPETII.DanmuAI-0.4.3-Setup.exe`，由 Velopack 管理安装和应用内更新。
- 便携版：解压 `PEPETII.DanmuAI-win-Portable.zip`，直接运行压缩包根目录的 `DanmuAI.exe`；不要把用户配置或 API Key 放入发布包。
- R2 是应用内更新的主源，GitHub Releases 是镜像下载源。首次使用时请在本地设置中填写自己的 provider、模型和 API Key。

## 构建产物

正式 Windows 产物由 `PyInstaller onedir → Velopack` 生成，位于 `release/velopack/`：

- `PEPETII.DanmuAI-win-Setup.exe`
- `PEPETII.DanmuAI-0.4.3-Setup.exe`
- `PEPETII.DanmuAI-0.4.3-full.nupkg`
- `PEPETII.DanmuAI-0.4.3-delta.nupkg`
- `PEPETII.DanmuAI-win-Portable.zip`
- `releases.win.json`
- `SHA256SUMS.txt`

代码签名未启用；如需签名，应按 `docs/operations/PACKAGING_WINDOWS.md` 的环境变量门禁执行，不要把证书或密码提交到仓库。
