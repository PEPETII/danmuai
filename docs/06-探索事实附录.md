## A.7 配置与并发

### A.7.1 ConfigStore 加密机制

- 加密库：`cryptography.fernet.Fernet`
- 密钥文件：`%APPDATA%/DanmuAI/.key`
- 数据库：`%APPDATA%/DanmuAI/config.db`
- 密钥丢失：旧 `api_key_encrypted` 不可恢复
- 密钥损坏：best-effort 备份到 `.key.bak.<timestamp>`
- 无 cryptography 时：fail-closed，抛 `ConfigStoreCryptoUnavailableError`
- 文件权限：Windows `icacls /inheritance:r /grant:r USERNAME:F`

### A.7.2 ConfigStore 锁机制

```python
# app/config_store.py:159-161
self._write_lock = threading.Lock()        # 非可重入
self._pool_write_lock = threading.Lock()   # 弹幕库独立锁
```

- `_write_lock` 引用次数：**27 处**
- 文档警告（`app/config_store/storage.py:1021-1022`）：「`_write_lock` 是非可重入 `threading.Lock`；本方法**不能**在已持 `_write_lock` 的临界区内调用」
- SQLite：`check_same_thread=False` + `cached_statements=256` + `PRAGMA journal_mode=WAL` + `busy_timeout=5000`

## A.11 探索方法说明

本附录所有事实通过以下 3 个并行 search agent 收集：

1. **Agent 1**：根目录结构 + 配置文件 + 文件清单
2. **Agent 2**：main.py + 8 mixin + application/ 子包 + 循环依赖检查
3. **Agent 3**：app/ 代码组织 + 分层职责 + 错误处理 + 类型注解 + 重复代码 + 配置管理

每个 agent 独立执行，结果交叉验证后汇总。所有数字均来自实际 grep / Read 工具调用，非推测。
