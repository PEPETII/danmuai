问题 1关键配置全藏在弹窗里

服务商、API 密钥、模型 ID 都只在「+ 添加模型」弹窗中填写；tab 页面本身没有可见的密钥输入框，新用户面对空列表不知从何下手。

问题 2没有概念说明

页面未用一句话解释"模型档案 = 服务商 + 密钥 + 模型"，新用户不清楚"添加模型"到底要准备什么。

问题 3混入无关设置

「弹幕显示模式」属于显示设置，却放在"AI模型配置"里，新用户误以为它和模型有关，分不清主次。

问题 4模型与显示器关系不清

这里选了显示器，但"用哪个模型读它"散落在弹窗里，页面上没有把"默认识图模型 ↔ 显示器"的对应讲清楚。

问题 5隐藏的 legacy 字段

源码里有一整段 hidden 的 API 地址 / 密钥 / 模型字段。新用户（或排查时）会困惑"配置到底存在哪"。

▾ 设计说明：本次改版解决的 5 个核心问题
  • ① 加概念引导条。页面顶部一句话讲清"AI 模型档案 = 服务商 + 密钥 + 模型"，新用户先理解再操作。
  • ② 加 3 步快速开始。把"添加 → 设为默认 → 绑定人格"的必经路径显式成步骤卡，降低决策成本。
  • ③ 档案卡片增强状态。每张卡片直接显示「默认识图 ★ / 使用中 / 支持麦克风 / 配置不完整」，状态一眼可见，不再需要进弹窗确认。
  • ④ 讲清模型与显示器关系。把"识图显示器"和"默认识图模型"放在同一「识图设置」区块并互相说明，消除"配置存哪"的困惑。
  • ⑤ 移出无关项 + 引导式弹窗。把"弹幕显示模式"建议迁移到「弹幕显示」tab；同时在添加弹窗内对每个字段配"如何获取密钥"等内联帮助，把新用户真正卡住的入口做顺。
